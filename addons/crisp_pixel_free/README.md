# Crisp Pixel Free Theme

A free pixel-art fantasy RPG UI Theme (Oak & Brass) with 53 pieces at 1x-4x: buttons, panels, window, inventory slots, health and mana bars, dialogue box, check box, slider, 18 icons.

Free sampler of Crisp Pixel: https://anipixels.itch.io/crisp-pixel
Demo scene: `res://addons/crisp_pixel_free/demo/pixel_free_demo.tscn`
Documentation: https://github.com/Anipixels/crisp-pixel-free-theme
